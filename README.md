# Multi-Channel Marketing Data Unification (SQL)

## 🎯 Project Overview
The goal of this assignment was to consolidate fragmented marketing data from multiple sources (Facebook and Google Ads) into a single, unified "Source of Truth." This allows for a holistic view of campaign performance, spend, and ROI across platforms.

## 🛠️ Key Technical Skills
*   **Data Aggregation:** Merging disparate datasets using SQL.
*   **Schema Design:** Creating a unified table structure (`unified_marketing`) for streamlined reporting.
*   **Metrics Calculation:** Standardizing performance metrics like clicks, spend, and conversions across different naming conventions.

## 💡 Reflection & Learning
While this was originally part of a technical assessment, I have used this project as a benchmark for growth. Key takeaways included:
*   The importance of naming consistency when joining marketing APIs.
*   Thinking about scalability—how this table would handle 10+ data sources instead of two.
*   Focusing on "Clean Data" as the foundation for any meaningful business dashboard.
